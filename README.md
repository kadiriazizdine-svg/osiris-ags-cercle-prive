# Osiris AGS · Le Cercle Privé

Landing page statique (HTML, CSS, JS). Aucun build nécessaire.

- `index.html` : la page complète
- `assets/img/` : photos et captures en WebP

## Déployer
1. Pousse ce dossier sur un dépôt GitHub.
2. Sur Vercel : New Project > importe le dépôt > Framework : "Other" > Deploy.

## Modifier le lien d'inscription
Cherche `whatsapp.com/channel/` dans `index.html` et remplace le lien partout.
